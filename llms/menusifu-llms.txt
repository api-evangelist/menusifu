> MenuSifu is a U.S. restaurant technology company founded in 2014 that builds an all-in-one
> point-of-sale and restaurant operations platform, used by more than 15,000 active restaurants
> and supported from offices in New York, Los Angeles, Houston, Orlando, Silicon Valley and
> Chicago.

## What MenuSifu sells

- POS terminals, handheld POS and self-service kiosks
- Kitchen display systems and kitchen automation
- Electronic menus and order-status screens
- Online ordering and scan-to-order
- Waitlist and reservations
- Loyalty programs, coupons and SMS marketing
- Analytics and reporting
- Direct delivery-platform order integrations: DoorDash, Uber Eats, Grubhub, Fantuan, HungryPanda
- Sibling brands: USEZPAY (payment processing), MealKeyway (marketing), EZ Capital (financing),
  WeFood, ShowTop

## API surface

**MenuSifu publishes no public API.** As of 2026-08-25 there is no developer portal, no API
reference, no OpenAPI/AsyncAPI/GraphQL contract, no SDK, no webhook catalog and no
`.well-known/` document on any MenuSifu host.

- The public sitemap (https://www.menusifu.com/sitemap.xml) lists 286 URLs. None is a
  developer, API, integration-reference or documentation page.
- The production host `https://api.menusifu.com` is real and reachable, but a blanket Spring
  Security filter rejects every anonymous request — `/openapi.json`, `/swagger.json`,
  `/v2/api-docs`, `/graphql` and every `/.well-known/*` path all return HTTP 401
  `{"successful":false,"code":999,"msg":"Full authentication is required to access this resource"}`.
- `developer.menusifu.com`, `docs.menusifu.com`, `open.menusifu.com`, `partner.menusifu.com`
  and `status.menusifu.com` do not resolve.
- Integrations with delivery platforms are built bilaterally by MenuSifu and its partners
  (for example Otter's MenuSifu connector), not through a self-serve public API.

Do not attempt to call `api.menusifu.com`. It is the private backend for MenuSifu's own POS
apps, not an integration surface.
